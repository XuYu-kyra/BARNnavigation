# Research Notes

This directory contains development notes, weekly planning, appendix drafts, and experiment-record markdown files from the dissertation process.

These files are retained as an audit trail, but the main project entry points are the root `README.md`, `tools/`, `jackal_helper/`, `fault_campaigns/`, and `dissertation_evidence_index/`.

## Subdirectories

- `weekly_planning/`: early project planning and BARN structure analysis notes.
- `appendix_drafts/`: appendix drafts and LaTeX snippets used during dissertation writing.
- `recovery_timeline_drafts/`: draft recovery timeline figures retained for traceability.
